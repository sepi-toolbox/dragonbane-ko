# Dragonbane 한국어 번역 (dragonbane-ko)

Foundry VTT의 **Dragonbane / Drakar och Demoner** 게임 시스템을 한국어로 번역하는 모듈입니다.

## 번역 범위

| 대상 | 내용 | 방식 |
|---|---|---|
| 시스템 UI | 630개 i18n 키 전량 (캐릭터/NPC/몬스터 시트, 아이템 시트, 대화 상자, 채팅 카드, 설정, 경고 메시지) | Foundry 언어 팩 (`i18n/systems/dragonbane.json`) |
| 어드벤처 컴펜디움 | 시스템 동봉 「Dragonbane / Drakar och Demoner - System」의 소개 일지 4페이지(환영합니다! / 캐릭터 시트 / 추천 모듈 / 전투), 능력치 굴림 매크로 6종, 폴더명 | Babele (`translations/`) |

> 「Change Log」 페이지(약 39,000자의 시스템 변경 이력)는 원문을 유지합니다. 페이지 이름만 한국어로 표시됩니다.
> 스웨덴어판 일지·매크로(`Introduktion (Sv)`, `Slå ...-slag`)는 원문 그대로 둡니다.

## 설치

Foundry의 **모듈 관리 → 모듈 설치 → URL로 설치**에 아래 주소를 붙여 넣으세요.

```
https://github.com/sepi-toolbox/dragonbane-ko/releases/latest/download/module.json
```

## 요구 사항

- 게임 시스템 **Dragonbane / Drakar och Demoner** (v4.1 기준)
- 모듈 **Babele** — 컴펜디움 번역에 필요합니다. 시스템 UI 번역만 쓸 경우에는 없어도 동작합니다.
- Foundry VTT v13 이상 (v14 검증)

## 용어

번역어 기준은 [docs/용어집.md](docs/용어집.md)에 정리해 두었습니다.
공식 한국어판이 없으므로 시스템 원문(영어)을 직접 옮긴 것이며, 용어 제안·수정 요청은 이슈로 남겨 주세요.
