# 드래곤베인 번역 작업 규칙

이 문서는 Dragonbane 한국어 번역 작업에서 **항상 먼저 확인해야 하는 작업 규칙**입니다.
대화 기억이나 임시 판단보다 이 문서를 우선합니다.

## 1. 정본 우선순위

규칙 용어, 기술, 능력치, 상태이상, 주문, 영웅 능력, 몬스터 특성, 무기·방어구, 피해 유형, 질병·독 규칙 등은 임의 번역하지 않습니다.

다음 순서로 확인합니다.

1. `dragonbane-ko/docs/용어집.md`
2. `dragonbane-coreset-ko/docs/용어집-coreset.md`
3. 한국어 Core Set 실제 본문
   - 규칙서
   - 어드벤처
   - 솔로 모험
   - 캐릭터 시트
4. 기타 연결된 Dragonbane 한국어 저장소
5. 위 자료에서 확인되지 않을 때만 임시 번역

**검색 결과 없음 = 정본에 없음**으로 판단하지 않습니다.
중요 규칙 용어는 검색 결과만 보지 말고 실제 파일 본문을 직접 확인합니다.

## 2. 번역 전 강제 확인 절차

영문 원문을 받으면 다음 순서로 처리합니다.

1. 규칙 용어를 먼저 분리합니다.
2. 이 문서와 용어집을 확인합니다.
3. 용어집에 없으면 실제 Core Set 한국어 본문을 확인합니다.
4. 확인된 한국어 정본 용어를 먼저 고정합니다.
5. 그 용어를 사용해 문장을 번역합니다.
6. 출력 직전에 규칙 용어가 기존 정본 표기와 충돌하지 않는지 다시 확인합니다.

즉,

> 영어를 먼저 임의 번역한 뒤 정본에 맞추지 않습니다.  
> **정본 한국어 용어를 먼저 확보한 뒤 영어 문장을 번역합니다.**

## 3. 미확인 용어 처리

정본에서 직접 확인하지 못한 용어는 임의로 공식 용어처럼 단정하지 않습니다.

예:

- 잘못된 처리: `Virulence = 독성`이라고 추정하여 확정
- 잘못된 처리: `Virulence = 병독성`이라고 의미만 보고 확정
- 올바른 처리: 정본 본문을 확인하여 `Virulence = 감염도` 사용
- 그래도 찾지 못했다면: **정본 표기 미확인**이라고 명시

임시 번역은 정본 용어와 구분합니다.

## 6. 문체 규칙

### 도감 본문 / 테오도라 서술
- 1인칭 문학적 서술
- `~다`체
- 약간의 재치와 학자·여행가다운 개성은 유지
- 원문보다 수식이나 설명을 임의로 추가하지 않음
- 원문 정보량을 유지하며 누락하지 않음

### 규칙 / 능력치 / 몬스터 특성 / 공격표 / 무작위 조우 / 모험 씨앗
- `~습니다`체
- 규칙 의미를 우선
- 수치·조건·범위·행동 소모 여부를 누락하지 않음

### 대사
- 원문의 말투와 분위기를 유지
- 억지로 `~습니다`체로 바꾸지 않음

## 7. 구조 보존

- 실제 원문의 문단 구분을 보존합니다.
- PDF 줄바꿈은 문장으로 자연스럽게 이어 붙입니다.
- 표는 가능한 한 표 구조를 유지합니다.
- 제목/소제목은 명사형을 우선합니다.
- `ADVENTURE SEED = 모험 씨앗`
- `RANDOM ENCOUNTER = 무작위 조우`

## 8. 금지 사항

- 검색에서 안 나왔다는 이유로 임의 번역 확정 금지
- 사용자 기억만 믿고 정본 확인 생략 금지
- 의미가 비슷하다는 이유로 기존 정본 용어 교체 금지
- D&D 등 다른 시스템의 용어를 Dragonbane에 자동 적용 금지
- 정본 미확인 용어를 “공식/정본”이라고 표현 금지
- 번역 중 원문에 없는 설정·해설·수식 추가 금지

## 9. 새 대화에서도 적용하는 방법

Dragonbane 번역 작업을 시작할 때는 대화 컨텍스트와 관계없이 **이 파일을 먼저 읽고 시작합니다.**
용어 충돌이 발생하면 대화 기억보다 이 파일과 정본 용어집을 우선합니다.

새로운 정본 용어나 프로젝트 확정 표기가 생기면 이 파일에 추가하여 다음 작업부터 재사용합니다.
