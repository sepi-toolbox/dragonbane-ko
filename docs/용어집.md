# 드래곤베인 한국어 용어집

`dragonbane` 시스템 v4.1의 영문 원문(`lang/en.json`)과 대조한 번역어 표입니다.
**정본은 번역자의 한국어판 규칙서·어드벤처·캐릭터 시트(PDF)** 이며, 이 모듈과
[dragonbane-coreset-ko](https://github.com/sepi-toolbox/dragonbane-coreset-ko)는 모두 이 표기를 따릅니다.
근거 우선순위: 캐릭터 시트 > 규칙서 해당 정의 페이지 > 규칙서·어드벤처 다수 용례.

## 핵심 게임 용어

| 영문 | 한국어 | 시스템 키 | 비고 |
|---|---|---|---|
| Boon | 은총 | `DoD.ui.dialog.boons` | 규칙서 3장 「은총 & 파멸」 |
| Bane | 파멸 | `DoD.ui.dialog.banes` | 시트 「파멸 부여」 |
| Dragon (크리티컬) | 드래곤 | `DoD.roll.dragon` | |
| Demon (펌블) | 악마 | `DoD.roll.demon` | 괴물 Demon도 악마 |
| Push roll | 굴림 밀어붙이기 | `DoD.roll.pushButtonLabel` | |
| Death Roll | 죽음 굴림 | `DoD.roll.deathRoll` | |
| Mishap | 사고 | `DoD.tables.mishap*` | Magical Mishap = 마법 사고 |
| Power Level | 파워 레벨 | `DoD.enchantments.powerLevel` | |

## 원문 유지 항목

- 주사위 표기 `D`, `D4`~`D20`, 약어 `HP`, `WP`, 기호 `&`, `-`
- 브랜드·고유명: Dragonbane(본문에선 「드래곤베인」), Drakar och Demoner, Fria Ligan AB,
  Foundry VTT, Babele, Dice So Nice!, Year Zero Engine: Combat,
  Dragonbane - Core Set / Bestiary / Official Soundtrack, Duplicate Combatant(s)
- 키보드 키 이름: SHIFT, CTRL, Delete
