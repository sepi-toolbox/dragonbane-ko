# 드래곤베인 한국어 용어집

`dragonbane` 시스템 v4.1의 영문 원문(`lang/en.json`)을 기준으로 정한 번역어 대조표입니다.
정본(공식 한국어판)이 없으므로 **시스템 원문 → 한국어**를 직접 옮긴 결과이며, 아래 표가 이 모듈의 기준입니다.

## 핵심 게임 용어

| 영문 | 한국어 | 시스템 키 | 비고 |
|---|---|---|---|
| Boon | 이점 | `DoD.ui.dialog.boons` | |
| Bane | 불리점 | `DoD.ui.dialog.banes` | |
| Dragon (크리티컬) | 드래곤 | `DoD.roll.dragon` | 고유 규칙어, 음역 |
| Demon (펌블) | 데몬 | `DoD.roll.demon` | 고유 규칙어, 음역 |

## 원문 유지 항목

- 주사위 표기 `D`, `D4`~`D20`, 약어 `HP`, `WP`, 기호 `&`, `-`
- 브랜드·고유명: Dragonbane(본문에선 「드래곤베인」), Drakar och Demoner, Fria Ligan AB,
  Foundry VTT, Babele, Dice So Nice!, Year Zero Engine: Combat,
  Dragonbane - Core Set / Bestiary / Official Soundtrack, Duplicate Combatant(s)
- 키보드 키 이름: SHIFT, CTRL, Delete
